# E13: recoverable chunk storage and actual compatible partial reuse

Implemented atomic prediction chunks with an immutable numerical/source contract,
ordered unique IDs, finite probability checks, per-chunk hashes and atomic
manifest updates. A completed compatible chunk is a cache hit; interrupted
temporary data are ignored. A final file without a committed manifest entry
fails explicitly for reconciliation. Source changes, corruption, wrong row order,
duplicate writes and incomplete assembly are rejected. No failed GPU mutation is
automatically repeated.

The actual integration audit verifies all2048native-cache rows and256new context
rows against their aggregate arrays. Context joins the original896long rows to
the new256in the exact1152-row order, after a fixed128-row raw overlap check.
Both rank/device assignments, final peak allocated/reserved memory and monotone
whole-worker memory records pass. These peaks include loading and prior chunks;
they are not isolated allocations for individual chunks. All input/packing,
adapter/tokenizer/source and old retrieval hashes remain pinned.

The native teacher measures original-order probabilities only. Its generic chunk
store's unused aligned_swap field duplicates original for storage compatibility;
it is **not** an observed swapped prediction. The exported judge_cache.npz omits
that alias, and every native quality/repeatability calculation uses measured
original probabilities or the separately measured64-row swap diagnostic.
Classifier chunks contain both measured orientations. The audit records these
view semantics explicitly so the native storage alias cannot support an
equivariance claim.

Unit/integration checks exercise compatible resume without another fake inference
call, corruption and source mismatch, real full notebook-cell bookkeeping,
failed child exit and the owned-process watchdog. The fresh size-pilot Trainer
control also passed a real CPU learning loop, stopping on the current accepted
cycle and its fixed scheduler endpoint. The size GPU branch was not admitted.
