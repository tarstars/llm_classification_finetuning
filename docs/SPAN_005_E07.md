# E07: response text predicts source class with a portable sparse head

E07 completed its fixed CPU-only experiment and passed the advancement gate.
All 91,970 training-answer OOF predictions hold out entire prompt groups and purge
normalized duplicate answers from fitting. TF-IDF source loss is **2.938585**,
versus matched frequency-prior **3.822561**, gain 0.883977 with paired95%group
interval[0.872833,0.894219]. Source-class accuracy is **27.08%**, top5 **54.49%**,
macro recall12.98%,10-bin ECE0.02097. These are source metrics, not preference
accuracy or evidence of an incremental LoRA gain.

The cached Qwen-embedding linear control gives source loss 3.704803, accuracy 9.95%
and top5 31.88%. Both beat the frequency prior, but the sparse head is substantially
better under these fixed recipes. This does not establish a universal comparison
of representations: contexts differ (4K versus 6Kcharacters), and heads/settings
were fixed rather than tuned. The embedding head remains a research control
without a measured offline embedding-generation path in this zero-GPU span.

Training source counts define64 classes, including one rare-source bucket. All
learned IDF/scaling/coefficients/priors use fitting rows only. The three folds purge
846/832/776 training answers respectively; final fitting purges882 answers duplicated
in development, leaving91,088 answers. No development source label or preference
vote selects or fits a source model. No learned post-hoc source calibration was
added. Reported calibration is diagnostic on raw probabilities. All fits converged
without warnings (TF-IDF18–19 iterations; embedding25–26).

The final portable head scores11,492 development answers in 14.009s:0.001219s per
answer. Its frozen classifier-plus-source projection is18,849.34s for25,000assumed
hidden comparisons, with 20%margin/600 sreserve and source reload. Before H45, the
contract additionally includes the earlier conservative395.91 scold-setup allowance,
giving19,245.25s, below25,200s. This is a conditional projection using the prior
classifier profile and local CPU speed, not a measured new Kaggle end-to-end run.

Elapsed worker time **1,703.979s (28.40minutes)**; peak RSS **3.701 GiB**, below the
4h / 6 GiB limits. GPU use and external extraction are zero. Full vectors, actual fold
indices, serialized heads and source posteriors are private. Aggregate results:
[E07_results.json](../results/span_005/E07_results.json).

**Decision:** E07 done; portable TF-IDF passes held-out signal, finite coverage and
conditional CPU feasibility. H45 may test incremental preference value under its
unchanged nested protocol. Source attribution success alone is not adoption.
