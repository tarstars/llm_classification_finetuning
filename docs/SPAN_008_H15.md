# H15: teacher provenance prevents an independent local advantage claim

The audited public solution is the final five-fold Gemma2-9B adapter merge from
[LMSYS_BlackPearl](https://github.com/shyoulala/LMSYS_BlackPearl), exact commit
05ac9b917a99aac43bfe0dbcb30e6e83a38688be. It is a GitHub training repository;
the same identifier is not an available Hugging Face model. No weights were
downloaded and no teacher quality was measured in this audit.

Its preprocessing reads the original competition training data, assigns five
stratified folds with seed2025, and adds external deduplicated33K examples to
each fitting fold. Its final script averages the five adapters. Each original
training example therefore influences four component adapters. If the published
checkpoint follows this code and contains the same original competition rows,
our development and confirmation votes are already represented in the merged
teacher's training. This is an inference from the published protocol, not an
independent reconstruction of the checkpoint. The final merge cannot establish
an independent local teacher advantage.

The authors train supervised70B/72B teachers and distill into9B. This is useful
evidence for an architecture/training direction; it does not establish that our
current general judge is a suitable teacher. Actual distillation remains deferred.
The next valid pilot needs teacher provenance excluding evaluation groups,
measured advantage, a fixed training-only soft-label sample, matched CE-only and
CE+KL accepted exposure, and a separately costed confirmation/labeling campaign.
