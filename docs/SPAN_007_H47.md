# H47: direct linear strength regression is worse than the identity projection

The fixed direct-regression recipe fails its gate. **Stop this branch without
confirmation scoring, export qualification or submission.** No better source
predictor is adopted from this experiment.

there is no post-result selection of the better control as a new model.

The sparse input features are held fixed. Predictor capacity is not identical:
the identity head uses many class logits followed by a nonlinear softmax
projection, whereas this ridge head is a single linear function. The negative
result applies to this fixed practical recipe, not every possible continuous
strength predictor. It does show that changing the target alone is not enough
under the tested recipe. After v6's inconclusive transfer, more source variants
have lower priority than the backbone, retention and cheap structural work.

## Protocol, coverage and cost

The source stage uses the original **three** source folds and three grouped inner
folds; preference evaluation uses **five** outer and three inner folds. The initial
prose mistakenly called the source folds five. The code was already frozen to
iterate the actual saved folds. The [erratum](SPAN_007_H47_ERRATUM.md), recorded
before preference results, preserves that mistake without changing data, code,
grids or the clock. Final ridge penalty10 is the median of actual inner choices.

All rating graphs use fitting-pair votes only. Source fitting purges duplicate
held answers; final fitting purges development plus confirmation input duplicates.
Residual/calibration fitting and selection stay inside development groups. The
three matched residual features are rating difference, absolute difference and
mean. Original labels/splits are preserved. No confirmation target or held-out
model-name feature is used for practical predictions.

Source contract4b42e5a precedes fitting. Successful CPU elapsed **1,872.704seconds /
31.21minutes**, peak RSS **3.410GiB**, two numerical threads, zero GPU charge.
The original three-hour cap is unchanged. The separate replay audit rebuilds
deterministic feature transforms and applies saved coefficients; it does not fit
another candidate or select variants. Its actual status/time is recorded below.
