# E02: offline CUDA artifact works; numerical compatibility fails

The bounded experiment is complete. The portable artifact resolves its libraries,
detects both native T4s, passes arithmetic/class mapping checks and scores all64
fixed reference rows with Internet disabled. **Its raw probabilities fail the
predeclared cache-identity guard. Stop cache reuse and optional judge expansion.**
This is a completed experiment with a negative compatibility finding, not adoption
of a portable judge/calibrator pair.

output, not the failed partial local CUBLAS download.
