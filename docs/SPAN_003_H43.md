# H43: preserving tie probability loses to calibrated vector blending

The predeclared CPU experiment is complete. On the same **2,048 exploratory dev
rows / 1,953 groups**, conditional A/B blending with fixed classifier tie mass is
worse than the full-vector blend, and substantially worse than its symmetric
postcalibrated control. **Do not adopt tie preservation.** The useful finding is
that recalibrating the full-vector mixture improves its loss.

The selector chose vector-plus-calibration in every outer fold. Its gain over
plain vector blending is **0.010102 [0.004034, 0.015725]**, paired95% group
interval. Conditional blending loses **0.013657 [0.006383, 0.020403]** against
that calibrated control. The postcalibrated mixture gains **0.028418
[0.018655, 0.037419]** against the latest classifier on these same rows.
These are matched cohort results; none is a full-development or official score.

Five outer grouped folds evaluate predictions; three inner grouped folds select
among exactly the three declared families. Inner recipe fitting cross-fits the
component calibrators before weight fitting. Calibrators, weights, thresholds and
family selection exclude each evaluation group's labels. Parameters are frozen
on the original 2,048 rows for potential future reuse, with timestamp and input
hashes; JSON round-trip predictions were checked exactly. No new inference,
training, confirmation use or official submission occurred in this experiment.

The calibrated vector mixture improves aggregate binary tie BCE **0.562899 →
0.557648** and winner contribution **0.397098 → 0.373931** against the classifier.
Tie AUROC improves0.68762→0.69799, tie recall38.11%→43.15%. Its human-tie class
loss nevertheless slightly worsens. Preserving tie mass prevents the mixture
from using useful judge evidence in the aggregate tie channel. That interpretation
is supported by the matched metrics, not a proof that tie preservation always fails.

CPU execution of the shared H39/H43 analysis took **9.09 seconds**; no GPU charge.
Both experiments share this cost and cached artifacts, so do not add it twice.
Raw-order diagnostics and exact unchanged-packing retention are in the aggregate
report; the judge remains single-order, with no new both-order guarantee.
Development and prior H37 outputs were already inspected. Conditional bootstrap
intervals do not undo that selection history or correct every comparison.

The formula is a useful full-blend research control, **not a deployable candidate**:
full judge inference remains too slow until a measured runtime path says otherwise.
Applying suitable postcalibration to an affordable routed mixture is a grounded
next-span hypothesis; it was not an extra variant in this experiment. Original
human labels, cache hashes and all per-row predictions remain preserved privately
under `~/database/llm_classification_finetuning/runs/span_003`.
