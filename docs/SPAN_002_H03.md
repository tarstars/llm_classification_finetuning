## Matched experiment and quality

The original output contained optimizer, scheduler, scaler, Trainer and both
rank RNG states at selected checkpoint 800. Continuation preserves the original
schedule, seed, tokenizer, 1,024-token packing, LoRA configuration, training
partition and selection sample. It changes exposure; no paired-order training
or longer context was introduced. Historical checkpoint 877 is distinct from 800.

All **5,746 development rows / 5,211 groups** are present exactly once, with
labels checked against source truth. Both models average aligned original and
swapped probabilities before separate calibration within identical five grouped
folds. Secondary nested selection uses three inner grouped folds and three
predeclared symmetric calibration families. Intervals use 2,000 paired group
bootstrap draws, conditional on fitted OOF predictions. Development was already
inspected; no untouched-data or multiple-comparison guarantee is claimed.
Confirmation is unused.
