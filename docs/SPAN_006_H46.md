# H46: frozen source correction does not pass the transfer gate

The compact inferred-strength correction gives a small point gain, with uncertainty
including no improvement. **Do not promote it or run E08.** This is a frozen check
on historically inspected confirmation data, not untouched validation.

| Matched calibration | 0.946628 | 54.33% |

Uniform accuracy uses deterministic argmax tie breaking. Unclipped hard-majority
log loss is infinite when another class wins; the finite number explicitly clips
and renormalizes its probabilities. Accuracy and source attribution accuracy are
different metrics from the competition's preference log loss.

Positive gain means comparator loss minus candidate loss. All comparisons use the
same **5,746 rows / 5,174 prompt groups**, with 2,000 paired group resamples:

| Comparator | Strength gain | Paired group 95% interval |
| --- | ---: | --- |
| Matched calibration | 0.000876 | [-0.000390, 0.002173] |
| Style control | 0.000063 | [-0.001584, 0.001604] |
| Shuffled source | 0.000969 | [-0.000390, 0.002375] |
| Frozen classifier | 0.001408 | [-0.000010, 0.002947] |

The prespecified practical minimum is 0.001 versus calibration with a positive
interval, plus positive paired evidence versus style. All three requirements
fail. The result is inconclusive about a small effect; it does not prove that
source information is useless. Choosing the raw classifier as the new primary
comparator, selecting confidence slices, or refitting on confirmation would not
repair the failed gate. Intervals are conditional on frozen predictions and omit
training/selection uncertainty and historical cohort reuse.

## What limits the correction

Tie loss slightly worsens from 1.059188 for calibration to **1.059589** for strength;
tie recall falls from 38.68% to **37.95%**. Winner A/B conditional losses improve
slightly, and tie AUC barely changes (0.691694 to 0.691815). This correction does
not address the classifier's weak tie discrimination. Original versus aligned
swapped classifier decisions disagree on 24.92% of rows; frozen averaging and all
four residual heads pass exact swap checks.

The text source predictor gets **27.98%** of source classes correct, loss 2.860600.
Source accuracy is 28.32% on development after the union purge. Predicted strength
correlates 0.585 with known source ratings on confirmation, versus 0.594 on
development; RMSE is 0.477 versus 0.487. Mean top source probability is only 0.274.
This supports testing strength prediction directly rather than optimizing all
64 source classes, but does not establish a gain for that untested method.

Large source/input shift is not an obvious explanation here: source-frequency
total variation from training is 0.0325, the rare/unknown bucket is 0.096%, and
only 3.23% of confirmation answers exceed the source head's 4,096-character cap
(3.92% on development). Confirmation mean answer length is 1,335 characters,
versus 1,363 on development. These descriptive checks cannot rule out subtler
shift or redundant style information. Fixed confidence-bin gains are descriptive,
with no threshold selection or adopted gate.
