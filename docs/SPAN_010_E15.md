# E15: model, cohort and batch survive progress sanitization

The future-run controller now uses a separately testable event sanitizer.
It retains role/cohort only as bounded64-character identifiers and batch only
as a nonnegative integer. Unknown fields including prompt/answers/credentials
remain excluded. Existing aggregate telemetry remains available. Two fixtures
exercise realistic worker progress and invalid/private values. This change has
no effect on the accepted v9 notebook or predictions; historical source lives at
commit057370d and its exact Kaggle version4 remains unchanged.

Validation: tests/test_progress_events.py; existing controller tests and backlog
checks run before admission. No GPU execution was needed for E15.
